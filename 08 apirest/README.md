
# About
Preparing the API Rest environment.

# Steps

## Install Postman
- Install Postman in /opt folder

## Create shortcut for Postman
- Create file named postman.desktop in ~/Desktop folder.
```
[Desktop Entry]
Name=Postman
Type=Application
Exec=/opt/postman/Postman
Icon=/opt/postman/app/icons/icon_128x128.png
```

- On the desktop, right-click on the postman.deskop item and select item properties.

- Click on Permissions tab and check 'Allow executing file as program' option

- Now on the desktop again right-click on the postman.desktop item and select Allow Lauching
