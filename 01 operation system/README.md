
## About
Preparing the Ubuntu Linux Operating System.

## Steps

### Update operating system
```
$ sudo apt update
$ sudo apt upgrade
```

### Install basic tools

#### Text Editor
```
$ sudo apt install notepadqq
```

#### Image Editor
```
$ sudo apt install gimp
```

#### Audio Editor
```
$ sudo apt install audacity
```

#### Audio/Video Player/Converter
```
$ sudo apt install vlc
```
